# Kanbi v0.3.0-beta.4

This beta improves board refresh, navigation, and editing responsiveness and updates the Go toolchain to address standard-library security advisories. It supersedes beta.3 and remains a prerelease.

## Changes

- Runtime refresh and SQLite observation run away from keyboard processing. Stale results cannot replace a newer board selection, lifecycle transition, or unsaved editor buffer.
- Named-board projections avoid loading unrelated boards; bounded caches reduce repeated card previews, note rendering, image-capability probes, and successful Git observations.
- Long descriptions and notes use bounded viewport rendering. The bundled textarea improves long-body editing while preserving complete saves and Unicode cursor behavior.
- The maximum renderer cadence is 120 FPS. Unchanged frames emit no output; the higher cadence has a small measured idle CPU cost. Inline mode and navigation keys are preserved.
- Linux and macOS archives include the bundled Bubbles textarea license and build provenance.
- Builds require Go 1.26.9, which fixes the standard-library vulnerabilities reported by the release scan. Indirect networking dependencies are updated as well.

## Install and upgrade

Download the archive matching your platform and `SHA256SUMS`, verify the checksum, extract the archive, and install `kanbi` on `PATH`. Run `kanbi version` and `kanbi doctor`. Native CGO archives support Linux and macOS on amd64 and arm64; tmux remains the default runtime. See [installation instructions](https://github.com/carlotran4/kanbi/blob/master/docs/installation.md).

This release uses database schema 8, unchanged from beta.3. Older databases receive the existing forward migrations. Stop Kanbi UI/CLI writers and create a backup with the currently installed binary before upgrading:

```bash
kanbi backup "$HOME/kanbi-pre-v0.3.0-beta.4.kanbi"
```

Keep that backup and the prior binary until the upgrade has been exercised. To roll back, stop Kanbi processes, reinstall the prior binary, then restore its backup with `kanbi restore PATH --force`. This replaces current durable data; changes made after the backup are lost. Do not downgrade an unsupported newer schema in place.

## Beta limitations and qualification

Kanbi remains beta software. Large Master views and very long editable bodies can still be slower than ordinary boards; terminal rendering and emulator latency vary. These changes do not claim a renderer migration or eliminate all scrolling motion. There are no Windows, Homebrew, or distro packages.

Resume still requires a verified harness session reference; use repair or start fresh when capture is unavailable. Herdr and real harness/provider combinations depend on installed, authenticated third-party tools. Deterministic adapter tests and isolated fake-harness tmux checks cover release qualification; real Herdr, harness, GitHub, and Jira checks are not represented as passed unless separately recorded. No harness command or provider behavior changed in this release. Multi-day soak and stable qualification remain incomplete.

## Support and security

The latest beta receives best-effort fixes and security updates. Diagnostics logging is off by default. Inspect support bundles before sharing; full backups contain private board data and must not be attached to public issues.
